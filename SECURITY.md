# Security Policy

## Supported Version

Security fixes target the current `main` branch and the deployed GitHub Pages version.

## Reporting

Please do not publish sensitive security details in a public issue. Use GitHub's private vulnerability reporting when available, or contact the maintainer through the GitHub profile with a short summary and reproduction outline.

## Security Notes

- Keep the site static and avoid collecting personal data directly in the repository.
- Review any future form, analytics, or third-party script additions carefully.
- Do not commit private application materials, credentials, or private contact data.
- Keep external links and mailto targets intentional and reviewable.
